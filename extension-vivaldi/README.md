# Browser extension implementation

This directory contains the shared Chromium extension and its Windows native
engine. Its historical name preserves existing installation paths.

Start with the [project README](../README.md) for features, architecture,
requirements, browser support, installation, usage, testing, and maintenance.
Run **`install.bat` at the repository root**, then load this directory's
`extension` subdirectory in the browser extension manager.
